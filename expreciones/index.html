Infija, prefija y postfija

Tres formas de escribir la misma expresión. Lo único que cambia es dónde se coloca el operador respecto a sus operandos.

Infija (usual)A + B
Prefija (polaca)+ A B
Postfija (RPN)A B +

Las tres salen del mismo árbol

Cada expresión se puede dibujar como un árbol: el operador es el nodo y los operandos son sus hijos. Según cómo recorras el árbol para (A + B) * C, obtienes una notación distinta.

RecorridoOrdenResultado
Preordenraíz, izquierda, derecha* + A B C
Inordenizquierda, raíz, derecha(A + B) * C
Postordenizquierda, derecha, raízA B + C *
